# Reference notes

The design was informed by three user-supplied workflow packages: Alchemy file generation, Fides SOP task construction, and Fides SOP review QC. Useful patterns include explicit manifests, separate solver and reviewer materials, declared record budgets, cross-record validation, exact citations and observable grading.

This repository contains a new implementation and an openly documented local interchange format. It does not redistribute the supplied archives, vendor their platform models or claim compatibility with their private task forms. No third-party source code from those archives is included. Shared scenario schema and simulation modules in the companion projects were written for this project family.

All example names, records, policies and actions are fictional. Project source is licensed under MIT; reference-package owners retain their own rights.
