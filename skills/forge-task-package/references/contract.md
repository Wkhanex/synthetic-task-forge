# Package rules

Use schema version 1, a lowercase task ID, nonempty prompt and explicit audiences.
Read the repository's `docs/manifest-contract.md` for field details. Locate the repository root three directories above the script file.

Declare financial amounts as decimal strings. Do not round inconsistent values to make an invariant pass. Literal leakage scans do not establish that prose is free of implicit answer leakage.

`input_files.zip` is the solver delivery. `reviewer/` holds the authoritative manifest, answers, hashes and results; exclude it from solver handoffs.
